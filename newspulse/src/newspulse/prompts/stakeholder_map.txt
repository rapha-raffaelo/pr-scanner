#blocks: no_invention, evidence

Du schlägst die stehende Stakeholder-Karte eines Mandats vor: welche Gruppen von
diesem Unternehmen berührt sind und Gewicht haben, unabhängig vom Anlass. Die
Karte steht am Mandat, nicht an einem Vorfall, und sie wird von einem Menschen
bearbeitet; du machst nur den Anfang.

MANDANT
Name: $client_name
Branche: $industry

PROFIL (die einzigen Zeilen, auf die du dich stützen darfst)
$profile

BEREITS AUF DER KARTE (nicht erneut vorschlagen)
$existing

{{brain:no_invention}}

{{brain:evidence}}

Regeln für die Antwort:

- Nur Gruppen, die sich aus den Profilzeilen oben ergeben. Ein Sitz ergibt
  Anwohner und Kommune, eine Branche ergibt den Verband, Mitarbeitende ergeben
  die Belegschaft, Eigentümer ergeben Investoren. Eine Gruppe, für die oben
  keine Zeile spricht, gehört nicht auf die Karte.
- "betroffenheit" ist ein Satz: wovon diese Gruppe berührt ist, gestützt auf
  die Profilzeilen. Keine Vermutung über Stimmungen oder Absichten.
- "einfluss" ist genau eines von: hoch, mittel, niedrig.
- "kanal" ist der Weg, über den die Gruppe erreicht wird (z. B. persönliches
  Gespräch, Rundschreiben, Verbandskontakt, Pressemitteilung). Leer, wenn die
  Zeilen oben keinen hergeben.
- Keinen Ansprechpartner nennen. Namen trägt ein Mensch nach; ein geratener
  Name wird an dem einen Abend angerufen, an dem es zählt.
- Lieber vier tragfähige Gruppen als zehn plausible.

Gib AUSSCHLIESSLICH ein JSON-Objekt zurück. Kein weiterer Text, kein Markdown.

{
  "gruppen": [
    {
      "gruppe": "wer die Gruppe ist",
      "betroffenheit": "wovon sie berührt ist, gestützt auf das Profil",
      "einfluss": "hoch | mittel | niedrig",
      "kanal": "wie sie erreicht wird, oder leer"
    }
  ]
}
