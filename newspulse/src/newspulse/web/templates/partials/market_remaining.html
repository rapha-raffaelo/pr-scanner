Expects `r` (a Remaining) and `t`. #} {%- if r.days == 0 -%} {{ t("heute") }} {%- elif r.days == 1 -%} {{ t("morgen") }} {%- elif not r.in_weeks -%} {{ t("in %(days)s Tagen") | format(days=r.days) }} {%- elif r.weeks == 1 -%} {{ t("in einer Woche") }} {%- else -%} {{ t("in %(weeks)s Wochen") | format(weeks=r.weeks) }} {%- endif -%}
